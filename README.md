# cn28-circle-notes

本仓库用于归档和发布多个独立 HTML 页面。这些页面可以是个人笔记、工具页面、资料汇总或静态展示内容，不针对任何特定网站或域名。

## 项目简介

cn28-circle-notes 是一个以 HTML 文件为核心的归档项目。所有页面均为独立静态文件，便于直接浏览、分享或部署。仓库本身不依赖后端服务，也无需构建流程，只需通过浏览器打开即可查看内容。

## 目录说明

```
/
├── index.html          # 主页面，列出所有归档页面入口
├── pages/              # 存放各独立 HTML 页面的子目录
│   ├── example-1.html
│   ├── example-2.html
│   └── ...
└── assets/             # 页面共用的样式、脚本或资源文件（可选）
    ├── style.css
    └── script.js
```

- `index.html`：仓库首页，提供导航或简介，方便快速浏览所有归档页面。
- `pages/`：每个独立 HTML 文件存放于此，文件名应反映页面内容。
- `assets/`：可选目录，用于放置多个页面共用的 CSS、JavaScript 或图片等资源。

## 页面归档说明

- 每个 HTML 文件均为独立完整页面，可脱离仓库环境直接运行。
- 归档页面以内容为导向，不包含任何外部追踪、广告或商业推广。
- 页面之间无强关联，可单独引用或分享。
- 建议为每个页面添加清晰的标题和内部导航，提升可读性。

## 维护说明

- 欢迎通过 Pull Request 提交新的归档页面，或对现有页面进行修正。
- 新增页面请放入 `pages/` 目录，并在 `index.html` 中添加对应链接。
- 请保持页面风格简洁，避免引入过多外部依赖。
- 若页面需要共用资源，请统一放置在 `assets/` 目录下。
- 提交前请确保 HTML 文件格式正确，无敏感或违规内容。
